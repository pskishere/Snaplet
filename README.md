# Snaplet

原生 macOS 截图应用，使用 SwiftUI 与系统截图工具。需要 macOS 14 或更新版本。

## 运行

点击 Codex 的 Run，或运行 `./script/build_and_run.sh`。构建结果位于 `dist/Snaplet.app`，脚本会把签名后的应用安装到 `~/Applications/Snaplet.app` 并从那里启动，避免项目目录的文件同步元数据影响签名。需要安装 Xcode Command Line Tools 才能构建。

## 功能

- 区域截图：⌘⇧2，拖动选择区域，Esc 取消。
- 窗口截图：⌘⇧3，点击需要截取的窗口。
- 全屏截图：⌘⇧4，截取主屏幕。
- 自动保存 PNG 到 `~/Pictures/Snaplet`，可自动复制到剪贴板。
- 截图完成后静默保存和复制，不自动打开主界面；通过菜单栏的最近截图或「打开 Snaplet」查看。
- 历史截图预览、复制、另存为。
- 右键历史缩略图可在 Finder 中显示或移到废纸篓；删除当前截图后自动选择相邻截图，文件可从废纸篓恢复。
- 系统分享：点击预览下方的分享图标，通过 macOS 分享面板选择隔空投送、邮件等服务。
- 拖拽发送：从历史缩略图或主预览拖出原始 PNG 文件，放入支持文件拖放的应用。
- 延时截图：主界面设置菜单或菜单栏面板「更多」中选择立即、3 秒或 5 秒；截图前隐藏主窗口，倒计时显示在菜单栏，可打开面板取消。区域和窗口模式会在倒计时结束后进入系统选区交互。
- 各窗口独立留在所在的 macOS 桌面空间。
- 截图工作台布局：顶部截图入口、中央大图预览、底部历史胶片条，可缩放图片。按钮回弹、预览切换、复制成功反馈和空白状态浮动扫描动画会遵循系统「减少动态效果」设置。
- 菜单栏常驻截图图标，点击后可快速选择区域、窗口或全屏截图。关闭主窗口后仍可使用菜单栏；选择「打开Snaplet」恢复主窗口，选择「退出Snaplet」结束应用。

前台快捷键为 ⌘⇧2/3/4。全局快捷键为 ⌃⌥⌘2/3/4，分别对应区域、窗口、全屏截图。首次截图需要在系统设置的「隐私与安全性 → 屏幕与系统音频录制」中授权Snaplet，并重新启动。截图过程中应用窗口会隐藏，取消时恢复。

- 快速预览：选中截图后按空格，调用系统 Quick Look。
- 导出：选择 PNG 或 JPEG，调整尺寸比例和 JPEG 质量，保留原图。
- 标注：矩形、椭圆、箭头、画笔、高亮、文字、马赛克和递增序号；颜色、粗细和字号可调整。直接拖动已有标注移动，拖动控制点缩放形状或调整箭头端点，双击文字原位编辑；按住 Option 绘制重叠内容。选中后可删除，绘制、移动、调整样式和删除均支持撤销重做。复制图片不会生成文件，保存副本保留原图。
- 标注在独立窗口中打开，可拖动边缘调整大小、使用绿色按钮放大或全屏。文字输入框自动伸展，Return 完成输入、Esc 取消编辑；拖动文字时显示选中边框和居中参考线，Shift 锁定移动方向，方向键微调（Shift 为 10 像素）。
- 登录启动：通过设置菜单开启，使用 macOS 登录项服务。

开发构建使用固定的 Apple Development 证书签名，首次构建自动选择本机唯一的开发证书，将指纹保存在 `.codex/signing-identity`；之后始终使用这张证书。可用 `SNAPLET_SIGNING_IDENTITY` 显式指定证书。缺少证书时构建会报错，不会回退到临时签名。

从旧版临时签名切换到开发证书后，需要重新授权一次；之后保持签名身份、Bundle ID 和安装路径稳定，重编译通常可以保留授权。若更换证书或授权开关开启但截图仍失败，可关闭再开启 Snaplet 的屏幕录制授权，并重新启动应用。

当前版本不包含滚动长截图。开发版适合本机使用；对外分发需 Developer ID 签名和公证。

### 界面语言

默认跟随系统，支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语和俄语。系统语言按优先顺序匹配，支持区域变体；未支持的语言回退到英语。在截图设置菜单的“语言”中切换，即时更新并记住选择。主窗口和独立标注窗口使用融入顶部工具栏的原生 macOS 红黄绿窗口按钮。

### 预览查看

倍率以适应窗口为 100%，支持到 800%；底部可逐级缩放或选择倍率。双击图片在放大和适应窗口之间切换；放大后拖动或触控板滚动平移，捏合或按住 ⌘ 滚动围绕鼠标缩放。点击预览后可用方向键平移、Shift 加速、加减号缩放、0 或 Esc 复位。适应窗口时仍可将图片拖出到其他应用，放大时拖动用于查看。

### 更新与权限

设置菜单的“权限与更新”可查看屏幕录制授权、打开系统权限设置、重新检测及重启应用。返回 Snaplet 时自动刷新授权状态；缺少权限时截图会进入引导页面。

更新使用 Sparkle 和 [GitHub Releases](https://github.com/pskishere/Snaplet/releases)，支持手动检查、自动检查、签名验证、下载及安装重启。自动检查默认关闭，可在权限与更新页面开启。更新签名私钥保存在本机钥匙串的 `com.local.lightcapture.updates` 账户，公钥在 `Assets/UpdatePublicKey.txt`。不要重新生成或上传私钥。

准备发行包：`script/prepare_release.sh 1.0.1 2 release-notes.md`。版本使用三段数字，构建号必须递增；输出 `dist/releases/v1.0.1/` 的 ZIP 和签名 appcast，不安装或发布。公开分发前需用 Developer ID 签名及公证；当前 Apple Development 构建只用于开发验证。发布时先将 ZIP 上传到对应的 GitHub Release，确认下载地址有效，再更新仓库根目录的 appcast.xml。当前公开安装包为未公证的 Apple Silicon 预发布版本；稳定更新源暂未启用。

预览原图和历史缩略图分别缓存，历史列表按需加载；删除及新增记录局部更新。马赛克图像在第一次使用时生成，常规构建使用 Release 优化。

### 标注草稿与设置

不同截图使用各自的标注窗口，同一截图重复点击会恢复已有窗口（包括最小化窗口）。关闭或退出时，未保存的标注可选择保留草稿、丢弃或取消；草稿保存到 `~/Library/Application Support/Snaplet/AnnotationDrafts`，下次打开对应截图会恢复。复制或保存成功后会清除该截图的草稿。

自动复制和截图延时会在重启后保留。图库监听目录变化，并在返回应用时同步外部修改、删除和新增的截图；文件变化时清除旧缓存，保留仍存在的当前选择。导出、标注合成和文件写入在后台执行，处理中防止重复提交。

发行准备脚本会校验构建号高于已发布和本机已准备的版本，拒绝重复版本或覆盖输出目录，并合并已有更新源；无法获取在线更新源时停止准备，避免跳过校验。

回归检查：`swift test -c release`。测试使用独立临时目录与偏好域，不读写用户截图。
